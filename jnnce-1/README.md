# Tesseract — application source

Setup, usage and gesture reference live in the [root README](../README.md).
Keeping one copy avoids the two drifting apart.

Quick start from the repository root:

```bash
npm run setup
npm start
```

- `index.html` — landing page
- `app.html` — 3D workspace
- `app.js` — scene, gesture pipeline, model loading, AI client
- `style.css` — workspace styles
- `server/` — static hosting, Socket.IO relay, Gemini proxy
